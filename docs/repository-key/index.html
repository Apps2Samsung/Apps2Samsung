Make the key for your repository

Your repository signs its list of apps with a key, so Apps2Samsung can tell the list really comes from you. This page makes that key in your own browser. It is never sent anywhere: the page has no server behind it and loads nothing else.

Don't have a repository yet? Start at Apps2Samsung/repository-template.

That doesn't look like yourname/repository-name. You can paste the link too.

Making the key, this takes a few seconds...

This browser can't make keys. Open this page in a recent Chrome, Edge, Firefox or Safari.

1

Save a backup

Keep this file somewhere safe and private, for example in a password manager. Never share it or put it in your repository. If you lose it, everyone who added your repository has to approve a new key.

2

Put it in your repository as a secret

Open the "New secret" page In your repository: Settings > Secrets and variables > Actions > New repository secret.

Fill it in like this, then click Add secret:

Name: REPO_SIGNING_KEY
Secret: your key
3

Publish

Open Publish In your repository: Actions > Publish.

Click Run workflow, then the green Run workflow button.
